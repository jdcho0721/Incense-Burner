## 프로젝트 소개 / Overview

**감각의 고고학 2076: 잃어버린 향의 연대기**는 국보 백제금동대향로에 새겨진
다섯 봉우리의 산(山), 용(龍), 봉황(鳳凰), 연꽃(蓮)의 도상을 평면적 유물
정보가 아니라, 그 위에 새겨진 물성과 상상된 향(香)의 서사로 재구성한
작품입니다. 2076년이라는 가상의 시점에서, 이미 사라진 향을 감각으로
발굴한다는 사변적 설정으로 향로의 조형을 다시 짚어봅니다.

*Archaeology of the Senses 2076* reconstructs the iconography of the Baekje
Gilt-bronze Incense Burner — its five mountain peaks, dragon, phoenix, and
lotus — not as flat artifact information, but through materiality and an
imagined scent-narrative. Set at a speculative future point (2076), it
re-excavates a long-vanished fragrance through the senses.

> **"향은 사라졌지만, 그 향이 새겨 넣은 형태는 손끝에 남아 있습니다."**

## 주요 기능 / Features

### 🐉 도상 탐색 / Iconography Exploration
- 향로의 아래에서 위로, **용 → 연꽃 → 삼신산 → 봉황** 네 레벨을 차례로 탐색
- 레벨마다 고유한 사운드스케이프, 그림 음성 해설(Audio Description), 사유 질문 제공
- 질문은 레벨마다 세 가지 중 하나가 무작위로 제시되어, 다시 볼 때마다 새로운 사유를 이끔

### 🕰️ 사변적 서사 / Speculative Narrative
- 2076년의 **기술 중심 관점(Tech)** 과 2026년의 **인문학적 관점(Human)** 중 하나를 골라 "잃어버린 향"을 복원
- 네 레벨을 모두 마치면 선택에 따라 세 가지 **우주관 증명서** 중 하나가 발급됨

### 📱 모바일 터치·스와이프 / Mobile Touch & Swipe
- 화면 하단에 고정된 **① 용 ② 연꽃 ③ 삼신산 ④ 봉황** 레벨 버튼 — 한 번 눌러 바로 이동
- 좌우로 밀어 다음·이전 레벨, 아래로 밀어 창 닫기
- 스크린 리더 없이도 모든 음성 안내를 **화면 하단 자막 바**로 동시에 제공

### ♿ 접근성 / Accessibility
- **WCAG 2.1 AA** 준수 지향
- **TalkBack / VoiceOver** 지원 (WAI-ARIA 역할·라벨, 포커스 관리)
- 스크린 리더가 없어도 터치·마우스·스와이프만으로 같은 경험이 가능한 다감각 설계

## 작품 구성 / Structure

| 레벨 | 부위 | 주제 | 사운드스케이프 |
|:---:|---|---|---|
| ① | 하부 · 용(龍) | 지면의 진동 | 묵직한 베이스 드론 |
| ② | 몸체 · 연꽃(蓮) | 입자의 정화 | 싱잉볼 주파수 |
| ③ | 뚜껑 · 삼신산(三神山) | 초월의 지평 | 백제금의 선율 |
| ④ | 정점 · 봉황(鳳凰) | 영원한 정적 | 긴 여운 끝의 비움 |

각 레벨에서 관람객은 사운드를 듣고 질문을 읽은 뒤 두 관점 중 하나를 고릅니다.

- **1번 관점 · 2076년 (Tech):** 물리적·기능적 해석 → ⚠ 경고
- **2번 관점 · 2026년 (Human):** 생명력·정화·사유·평화의 해석 → ✓ 복원 성공

## 관람 방법 / How to Use

| 하고 싶은 것 | 방법 |
|---|---|
| 레벨 열기 | 향로 그림의 부위(이름표가 붙은 띠)를 누르거나, 하단 **①~④ 버튼**을 한 번 누르기 |
| 다음·이전 레벨 | 향로 위나 레벨 창에서 **좌우로 밀기** (왼쪽 = 다음, 오른쪽 = 이전) |
| 사운드 듣기 | **[🔊 사운드 신호 해독]** 버튼 (다시 누르면 일시 정지) |
| 그림 해설 듣기 | 레벨 창의 그림(**Audio Description** 표시)을 누르기 — 다시 누르면 중단 |
| 글 다시 듣기 | 창 안의 제목·질문·결과 글을 누르면 그 글을 읽어 줌 |
| 관점 고르기 | 두 선택지 중 하나를 누르기 → 결과와 **[✕ 로그 닫기]** 버튼이 나타남 |
| 창 닫기 | **아래로 밀기**, 창 바깥 누르기, **[✕ 로그 닫기]**, 또는 `Esc` |
| 증명서 | 네 레벨을 모두 마치면 하단의 **📜 증명서** 버튼 또는 상태 패널의 발급 버튼 |
| 작품·사용법 안내 | 제목 아래 **[ⓘ 아카이브 가이드]** — 마우스를 올리면 잠시 뒤 자동으로 열림 |
| 키보드 | `Tab`·방향키 이동, `Enter`/`Space` 선택, 레벨 창에서 `←` `→` 레벨 이동, `Esc` 닫기 |

하단 버튼과 향로 위 이름표는 상태에 따라 바뀝니다 — 보는 중(청록으로 채움), **✓ 복원**(파랑), **⚠ 경고**(주황). 버튼 위 막대는 전체 진행률입니다.

## 스크린 리더 없이 쓰는 접근성 설계 / Accessibility without a Screen Reader

**보이는 자막 / Live Captions**
- 제목 안내, 결과, 그림 해설, 증명서까지 모든 음성을 화면 하단 자막 바에 동시에 표시
- 3줄 높이로 제한해 화면을 덜 가리고, 길면 자막 안을 밀어 읽음 · **접기**(한 줄) / **닫기**
- 자막이 떠 있을 때는 레벨 창이 자막 위 공간까지만 차지해 버튼이 가려지지 않음

**누르기 쉽게 / Large Touch Targets (Fitts's Law)**
- 모든 버튼 최소 48px, 하단 레벨 버튼과 관점 선택지는 56px
- 부위 띠는 향로 가로 전체를 덮어 어디를 눌러도 반응하고, 누른 자리에 원형 피드백 표시
- 더블탭 확대 지연 없이 즉시 반응 (두 손가락 확대는 그대로 가능)

**화면 배치 / Responsive Layout**
- 세로: 향로 그림의 원래 비율(600:850)을 지키며 한 화면 안에 전체가 보이도록 맞춤
- 가로(휴대폰): 제목은 왼쪽, 향로는 오른쪽 / 레벨 창은 그림 왼쪽, 질문·버튼 오른쪽
- 아이폰 노치·홈 표시줄 영역(safe area) 대응, "동작 줄이기" 설정 시 애니메이션 최소화

## 작품 배경 / Background

백제금동대향로는 백제 시대(6~7세기)에 제작된 것으로 추정되는 국보로,
불교와 도교적 세계관이 함께 새겨진 정교한 조형으로 널리 알려져 있습니다.
이 작품은 그 조형에 실제로는 전해지지 않는 "향"이라는 감각을 상상으로
채워 넣어, 유물을 시각 정보가 아닌 다감각 경험으로 재구성합니다.
백제금동대향로 원본은 국립부여박물관에 소장되어 있습니다.
